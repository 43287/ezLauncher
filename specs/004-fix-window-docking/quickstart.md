# Quickstart & Validation Guide: fix-window-docking

本指南用于验证窗口停靠（Docking）与尺寸计算（Size Calculation）相关的修复。

## Prerequisites

- Windows 10/11 操作系统。
- Node.js (v18+) 与 Rust 工具链就绪。
- 项目已通过 `npm run build` 和 `cargo clippy` 的静态检查。

## Validation Scenarios

### 1. 窗口动态伸缩锚点验证 (FR-003)

**目的**：验证无论窗口高度还是宽度如何变化，停靠侧的贴边状态绝不松动。

1. 启动应用，在设置中将“侧边停靠”设置为 **右侧**。
2. 呼出应用，此时应用应当紧贴屏幕右边缘。
3. 从外部拖拽一个任意文件进入应用网格区域（此时窗口高度可能会增加或减少，视内容而定）。
4. **验证**：拖入过程中和结束后，应用的最右侧边缘必须始终与显示器右边缘保持 0px 的缝隙。
5. 进入设置，将“网格列数”从 `4` 修改为 `2`，然后再修改为 `6`。
6. **验证**：应用宽度变化时，必须始终是以右边缘为锚点向左侧伸缩。

### 2. 消除横向滚动条验证 (FR-001, FR-002)

**目的**：验证网格宽度的精确计算以及溢出隐藏策略的生效。

1. 启动应用，在设置中将“网格列数”设置为 `4`。
2. 确保您当前分类下的应用数量足够多，触发了**纵向滚动条**的出现。
3. **验证**：观察应用面板的底部，绝对不能出现**横向滚动条**。
4. **验证**：观察网格中最右侧的那一列图标，它们不应该被截断，且右侧距离纵向滚动条应该留有合理的呼吸空间。

### 3. "添加分类" Tooltip 移除验证 (FR-004)

**目的**：验证多余的文字提示已被清理。

1. 启动应用。
2. 将鼠标悬停在左侧分类栏底部的 `+` 按钮上。
3. 保持悬停不动等待 5 秒钟。
4. **验证**：不应该有任何原生的黑色/白色 `添加分类` 的提示框（Tooltip）弹出。
